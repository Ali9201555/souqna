# Souqna · سوقنا

**Iraq's trusted local marketplace** — a mobile-first app for buying and selling
locally (cars, phones, real estate, furniture, services…), in the spirit of
Facebook Marketplace but built for Iraq: Arabic-first, RTL throughout, with
Kurdish and English support.

> Status: **MVP UI complete and running on an in-memory data layer.** The
> backend (Supabase) schema is written but not yet wired to the app. See
> [ROADMAP.md](ROADMAP.md) for what's next.

---

## Tech stack

| Concern | Choice | Why |
| --- | --- | --- |
| Framework | **Expo SDK 56** (React Native 0.85, React 19) | iOS + Android + web from one codebase; cloud iOS builds via EAS (no Mac needed) |
| Language | **TypeScript** (strict) | Agent-friendly, catches errors before runtime |
| Routing | **expo-router** (file-based, typed routes) | `Stack` + `(tabs)` group + dynamic `listing/[id]` |
| State (now) | React context (`src/data/ListingsProvider.tsx`) | In-memory store shaped to match Supabase inserts |
| Backend (next) | **Supabase** — Postgres + phone/OTP auth + Storage + RLS | Schema in `supabase/migrations/` |
| i18n | Custom lightweight provider | Arabic (default), Kurdish (Sorani), English |
| Icons / images | `@expo/vector-icons` (Ionicons), `expo-image` | — |

## Quick start

```bash
npm install
npx expo start        # then press i / a / w, or scan the QR with Expo Go
```

Other scripts:

```bash
npm run typecheck     # tsc --noEmit  (must stay clean)
npm run lint          # expo lint
npx expo export --platform web   # smoke-test the whole module graph bundles
```

> **Note:** `expo-env.d.ts` is auto-generated by Expo (and git-ignored). It is
> created the first time you run any `expo` command. If `npm run typecheck`
> reports missing `*.css` module types on a fresh clone, run `npx expo start`
> once to regenerate it.

## Building for devices (no Mac required)

iOS and Android release/preview builds run in the cloud via **EAS Build**:

```bash
npm i -g eas-cli
eas login
eas build --platform ios --profile preview     # cloud-signed, installable
eas build --platform android --profile preview
```

(EAS project config is added when we first cut a build — see the roadmap.)

## Project structure

```
src/
  app/                      # expo-router routes
    _layout.tsx             # providers + root Stack
    (tabs)/                 # Home, Search, Sell, Chats, Profile
    listing/[id].tsx        # listing detail
  components/               # reusable UI (Screen, ListingCard, PickerSheet, Avatar…)
  constants/theme.ts        # Colors (light/dark), Spacing, Radius
  data/                     # categories, governorates, seed data, ListingsProvider
  i18n/                     # LanguageProvider + translations (ar / ku / en)
  lib/format.ts             # price + relative-time formatting
  types/index.ts            # domain types (Listing, SellerProfile, ChatThread…)
supabase/
  migrations/               # 0001 schema · 0002 RLS · 0003 storage
  seed.sql                  # categories + governorates reference data
```

## Architecture notes

- **Arabic-first & RTL.** Default language is `ar`. RTL is handled with explicit
  `isRTL` styling (`flexDirection: 'row-reverse'`, `textAlign: 'right'`) rather
  than relying solely on `I18nManager`, so layout is correct on web and native
  without a reload. English/Kurdish strings fall back to English when missing.
- **Swappable data layer.** Screens talk only to `useListings()`. The in-memory
  store returns the same shapes a Supabase query/insert will, so wiring the
  backend should not require screen changes — only swapping the provider's body.
- **Money.** `priceIqd` is an integer in Iraqi Dinar; `0` means "contact for
  price". No floats.
